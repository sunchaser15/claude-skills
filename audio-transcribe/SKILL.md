# Транскрипция с вычиткой

Два шага, и **второй обязателен**. Сырой вывод Whisper пользователю не отдаём:
на русской речи он стабильно перевирает имена, термины и даты, а это ровно то,
ради чего запись и расшифровывают.

## Шаг 1. Распознавание

```bash
~/.local/share/whisper-transcribe/.venv/bin/python \
  ~/.agents/skills/audio-transcribe/scripts/transcribe.py \
  "<аудио>" "<scratchpad>/<имя>" ru
```

Запускай в фоне (`run_in_background`): час записи — около двух минут на GPU.
Получается `<имя>.txt` (строки `[чч:мм:сс] текст`), `<имя>.plain.txt` и `<имя>.json`.

Первый в жизни запуск тянет модель (~1.6 ГБ). Если загрузка рвётся, повтори с
`HF_HUB_DISABLE_XET=1` — xet-загрузчик молчит и выглядит как зависший.

Если venv нет, собери:
`uv venv --python 3.12 ~/.local/share/whisper-transcribe/.venv && uv pip install --python ~/.local/share/whisper-transcribe/.venv/bin/python mlx-whisper numpy`

## Шаг 2. Вычитка

Прочитай транскрипт целиком — да, весь. Ошибки распознавания видны только из
контекста: «триггерность ученарства» опознаётся как «древнерусское государство»
лишь по соседним фразам, а «Майкл Фридман» выглядит правдоподобно, пока не
вспомнишь, что монетаризм — это Милтон.

Собирай правки в файлы `fixes1.py`, `fixes2.py`, ... по 100–200 строк:

```python
# -*- coding: utf-8 -*-
FIXES = {
    "00:12:30": "Исправленная реплика целиком.",
    "00:12:30.1": "Вторая реплика с тем же таймкодом (суффикс .1, .2, ...).",
    "00:12:34": "[неразборчиво]",
}
```

Применяй **только** через скрипт — он сажает правку по совпадению текста, а не
по таймкоду, и ловит съехавшие:

```bash
python3 ~/.agents/skills/audio-transcribe/scripts/apply_fixes.py \
  "<имя>.txt" fixes1.py fixes2.py -o "<имя>_clean.txt"
```

Скрипт печатает коллизии, ключи без строки и слабые совпадения. **Разбери
каждое** — это почти всегда ошибка в словаре. Потом сверь незатронутые строки
(`diff` исходника и результата) и добери пропущенное.

### Что править

- **Имена и термины** — главное. Один и тот же термин часто распознан
  по-разному в разных местах: приведи к одному виду.
- **Даты.** Whisper дописывает тысячелетие: `862 -> 1862`, `945 -> 1945`,
  `988 -> 1988`. В лекциях по истории и праву это критично.
- **Пунктуация** на участках, где модель ушла в поток строчных букв без точек.
- **Зацикливания** в тишине («в инфляции, в инфляции, в инфляции») — в `[неразборчиво]`.

### Чего не делать

**Не выдумывай текст.** Если за шумом не разобрать — ставь `[неразборчиво]`.
Лучше честный пропуск, чем правдоподобная выдумка в учебном конспекте.

**Не чисти повторы, не разобравшись.** Когда лектор диктует под запись, он
повторяет каждую формулировку дважды — это содержание, а не дефект.

## Результат

Два файла рядом с исходником, с шапкой: что за запись, длительность, содержание
с таймкодами и **таблица исправлений** (что на что заменено) — по ней можно
свериться с записью.

- `<имя> — транскрипт (вычитано, с таймкодами).txt`
- `<имя> — транскрипт (вычитано).txt` — сплошной текст абзацами

Отдавай через SendUserFile. В ответе скажи, сколько строк поправлено, сколько
помечено `[неразборчиво]`, и назови места, где восстанавливал смысл с меньшей
уверенностью.

## Если файл не читается

Записи из «Диктофона» лежат в `~/Library/Containers/com.apple.VoiceMemos/`,
куда macOS не пускает без Full Disk Access — будет `Operation not permitted`.
Не бейся с правами: попроси перетащить файл в `~/Downloads` через Finder.
