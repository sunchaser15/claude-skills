# Типографика (русский язык в приоритете)

Все шрифты ниже проверены по базе `ui-ux-pro-max/data/google-fonts.csv`: у каждого есть подмножество **cyrillic**. Это важно: много модных гротесков кириллицы не имеют, и русский текст тихо уходит в системный шрифт.

## Не подходят для русского (нет кириллицы)

Space Grotesk, Bricolage Grotesque, Fraunces, Instrument Serif, DM Sans, Syne, Figtree, Outfit, Sora, Urbanist, Lexend, Gabarito, Schibsted Grotesk, Albert Sans, Newsreader, Kanit.

**Только `cyrillic-ext`, без базовой кириллицы** (русские буквы НЕ отрисуются этим шрифтом): Plus Jakarta Sans, Hanken Grotesk.

Если дизайн сильно хочет такой шрифт, ставь его только на латинские слова и логотип, а русский текст отдавай шрифту с кириллицей.

## Пары (заголовок + текст)

Фильтр antislop (R-06): шрифт выбирается **по характеру бренда с записанной причиной**, а не потому что это дефолт модели (Inter, Geist, Space Grotesk, моноширинные «под терминал»). Inter допустим, если причина записана. Капс с широким трекингом для меток («КАК ЭТО РАБОТАЕТ») и большой моноширинный заголовок без смысла запрещены по умолчанию.

## Подключение (минимум трафика)

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Onest:wght@400;500;600&family=Unbounded:wght@600;800&display=swap&subset=cyrillic,latin" rel="stylesheet">
```

Для продакшена надёжнее скачать woff2 и раздавать с собственного домена (у части провайдеров Google Fonts может подтормаживать): `@font-face { font-family: Onest; src: url(/fonts/onest.woff2) format('woff2'); font-weight: 400 600; font-display: swap; unicode-range: U+0400-04FF, U+0000-00FF; }`. Вариативные файлы дают весь диапазон начертаний одним запросом.

## Шкала размеров (текучая)

```css
:root {
  --step--1: clamp(0.8125rem, 0.79rem + 0.1vw, 0.875rem);   /* мелкий */
  --step-0:  clamp(1rem, 0.96rem + 0.2vw, 1.125rem);        /* текст */
  --step-1:  clamp(1.25rem, 1.15rem + 0.5vw, 1.5rem);
  --step-2:  clamp(1.5rem, 1.3rem + 1vw, 2.125rem);
  --step-3:  clamp(2rem, 1.5rem + 2.2vw, 3.25rem);          /* h2 */
  --step-4:  clamp(2rem, 0.9rem + 4.8vw, 5rem);              /* h1 */
  --step-5:  clamp(2.125rem, 0.2rem + 8.4vw, 7.5rem);      /* герой-плакат */
}
```

Русские слова длиннее английских в среднем на 15–25%: заголовок, влезающий по-английски, по-русски переносится. Для русских заголовков бери на ступень меньше или сокращай текст, не режь трекинг до нечитаемости.

## Правила

- **Не больше двух семейств**, не больше трёх начертаний в сумме. Иерархия — размером и весом, а не новым шрифтом.
- **Основной текст**: 16–18 px (`1rem`–`1.125rem`) минимум, межстрочный 1,5–1,7, ширина строки 60–75 знаков (`max-width: 65ch`).
- **Заголовки**: межстрочный 1,0–1,15, трекинг −0,02…−0,04em на больших размерах; чем меньше размер, тем ближе трекинг к нулю.
- **Метки капсом** не используй по умолчанию (R-06). Если фирменный приём из DESIGN.md требует их, то только на 11–13 px и коротко, причина записана. Длинный русский текст капсом читается плохо.
- **Переносы и баланс**: `html { hyphens: auto; }` с `lang="ru"`, `h1,h2,h3 { text-wrap: balance; }`, `p { text-wrap: pretty; }` (убирает «висячие» одиночные слова).
- **Неразрывные пробелы**: после коротких предлогов и союзов (в, на, и, с, к, по, за, от), между числом и единицей (`10&nbsp;ГБ`, `5&nbsp;₽`), в «т. е.». Тире — длинное «—» с неразрывным пробелом перед.
- **Типографские знаки**: «ёлочки» вместо "лапок", многоточие `…`, минус `−`, `×`, апостроф `’`. Букву «ё» не терять в именах и в словах, где она меняет смысл (всё/все).
- **Цифры**: `font-variant-numeric: tabular-nums` в таблицах, ценах и счётчиках, чтобы колонки не «плавали».
- **Вес и контраст**: на тёмном фоне светлый текст кажется жирнее, поэтому для основного текста бери 400, а не 300; тонкие начертания (100–300) только на крупных размерах.
- **Выделение**: акцент — весом (600) или цветом `--primary`, подчёркивание оставляй для ссылок. Курсив для русского — редко и коротко.
- **Числа в героях**: огромные цифры (`--step-5`) в моноширинном или геометрическом шрифте с короткой подписью — один из самых «дорогих» приёмов.
- **Совпадение метрик**: подбирай запасной шрифт с близкими метриками (`size-adjust`), чтобы при подмене страница не прыгала.
