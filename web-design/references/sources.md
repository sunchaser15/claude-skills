# Источники и что откуда взято

Сведено 07.10.2026 из открытых материалов; проверено лично: контраст палитр (скрипт), кириллица шрифтов (база Google Fonts из `ui-ux-pro-max`), рабочий код шаблонов (прогнан в браузере).

- **antislop** (`github.com/miqdadbadjuber/anti-slop`, MIT, v3.2.20): фильтр против шаблонного ИИ-дизайна. Установлены шесть скиллов: `antislop` (ядро), `antislop-ui`, `antislop-copywriting`, `antislop-human` (с `contrast-check.py`), `antislop-layoutmobile`, `antislop-code`. Это **фильтр, а не гайд по стилю**: направление даёт `DESIGN.md`. Обновление: `npx antislop-ai --update`.
- **21st.dev** (каталог 12 000+ компонентов, поиск открыт, `robots.txt` разрешает `search` и `ai-input`): поисковые страницы в виде текста `https://21st.dev/community/components/s/<запрос>.md`, страницы компонентов `…/@автор/components/<имя>.md` (в них лицензия и зависимости). Использую **только как вдохновение**; код чужих компонентов не копирую без проверки лицензии автора.
- **Эмиль Ковальски** — `github.com/emilkowalski/skills` (MIT): решения про анимацию, кривые, длительности, формат ревью «До/После». Установлены: `emil-design-eng`, `animation-vocabulary`.
- **ui-ux-pro-max** — `github.com/nextlevelbuilder/ui-ux-pro-max-skill` (MIT): локальная база (192 палитры по типам продуктов, 74 пары шрифтов, 119 UX-правил, 79 стилей, пресеты GSAP, 22 стека) и поиск `scripts/search.py`. Установлен целиком, без тестов. Подбор по запросу бывает неточным (запрос «dark premium SaaS» вернул автосалон) — результат всегда сверяй с брифом.
- **GSAP** — `github.com/greensock/gsap-skills` (MIT, официальные): 8 скиллов (core, scrolltrigger, plugins, timeline, performance, utils, react, frameworks).
- **Three.js** — `github.com/cloudai-x/threejs-skills`: установлены `threejs-shaders`, `threejs-fundamentals`, `threejs-animation`; остальные (geometry, lighting, materials, loaders, textures, postprocessing, interaction) докопируй при необходимости.
- **ibelick/ui-skills** (MIT): установлен `fixing-motion-performance`; также есть `baseline-ui`, `fixing-accessibility`, `improve-ui`, `create-design-md`.
- **Impeccable** — `github.com/pbakaus/impeccable` (Apache-2.0): режимы Persuade/Operate/Read/Experience и антишаблоны оттуда. **Не установлен**: лаунчер скачивает бинарник при первом запуске, и скилл тяжёлый; если нужна его команда `audit/polish/live`, ставь осознанно.
- **WCAG 2.2** (w3.org/TR/WCAG22), **Core Web Vitals** (web.dev/vitals), **Nielsen Norman Group** (10 эвристик), **MDN** (`prefers-reduced-motion`, scroll-driven animations, View Transitions).
- **Лендинги для вдохновения (смотреть, не копировать)**: linear.app, vercel.com, stripe.com, raycast.com, resend.com, arc.net, cursor.com, family.co, lusion.co, active-theory.com; подборки: awwwards.com, godly.website, land-book.com, mobbin.com, httpster.net, onepagelove.com.
- **Dribbble** (dribbble.com, добавлен по правилу владельца 08.10.2026): дизайн экранов, лендингов и брендов от дизайнеров. Поиск `https://dribbble.com/search/<запрос-через-дефисы>` открыт в `robots.txt`, но `curl` получает защиту от ботов (код 202, пустое тело), поэтому только встроенный браузер; в окне cookie жать «Reject All». Работы `/shots/<id>-<название>`. Кода и лицензии нет: это чужие макеты, берём приём, а не картинку.
- **Компоненты**: 21st.dev, ui.shadcn.com, magicui.design, ui.aceternity.com, reactbits.dev — брать куски и приводить к своим токенам, не складывать как есть.
- **Shaders** — `github.com/shader-effects-inc/shaders` (MIT, проверено 08.10.2026): 199 WebGPU-эффектов компонентами, справочник `shaders.com/llms-full.txt`. Только WebGPU, без WebGL. Свой скилл и MCP у них есть, **не установлены** (см. `motion.md`, раздел «Готовая библиотека»).
- **Шейдеры и эффекты**: thebookofshaders.com (учебник), shadertoy.com, iquilezles.org/articles (приёмы), codrops (разборы эффектов), tympanus.net/codrops.
- **Иконки**: lucide.dev, phosphoricons.com. **Шрифты**: fonts.google.com, fontshare.com (проверять кириллицу!), rsms.me/inter.
