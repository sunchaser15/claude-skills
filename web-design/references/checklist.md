# Чеклист перед сдачей и инструменты проверки

**Главный документ проверки: Delivery Gate из скилла `antislop`** (четыре блока: Hard Gate, Purpose-Gate, Liveliness, Craftsmanship). Этот чеклист его дополняет. Отчёт сдаётся как PASS/FAIL, у каждого PASS указано доказательство (что запускал, что нажимал, что показала консоль). Любой FAIL значит «не сдавать».

Всё, что идёт ниже, это рабочая быстрая проверка по ходу; в конце всё равно прогоняется полный Delivery Gate и результат записывается в раздел 15 файла `DESIGN.md`.

## Быстрая проверка (отметь каждый пункт честно)

**Смысл и структура**
- [ ] На первом экране понятно: что это, для кого, что делать (заголовок, подзаголовок, одна главная кнопка).
- [ ] У каждой секции есть одна задача; лишние убраны.
- [ ] Тексты реальные, цифры настоящие; нет lorem ipsum и выдуманных отзывов.

**Визуал**
- [ ] Цвета только из токенов; один основной + один акцент; нет сырых hex в компонентах.
- [ ] Не более 2 семейств шрифтов; у выбранных есть кириллица; размеры из шкалы.
- [ ] Отступы из шкалы 4/8; выравнивание по общим линиям; радиусы согласованы.
- [ ] Иконки одного набора, не эмодзи; изображения качественные и обрезаны осмысленно.

**Удобство**
- [ ] Все цели нажатия ≥ 44×44 px; между ними ≥ 8 px.
- [ ] Есть состояния: hover (только при `hover: hover`), focus-visible, active, disabled, loading, error, empty.
- [ ] Клавиатура: Tab проходит всё в логичном порядке, фокус виден, Esc закрывает окна.
- [ ] Формы: метки видны, ошибки у поля, правильные `type`/`autocomplete`/`inputmode`.

**Адаптив**
- [ ] Проверено на 375, 768, 1024, 1440 (и 320 не ломается); нет горизонтальной прокрутки.
- [ ] `100dvh` вместо `100vh` на мобильном; безопасные зоны для липких панелей.

**Доступность**
- [ ] Контраст: текст ≥ 4,5:1 (цель 7:1), крупный и элементы ≥ 3:1 (проверено формулой, не «на глаз»).
- [ ] Один `h1`, заголовки по порядку, `lang="ru"`, `alt` где нужен, `aria-label` у иконок-кнопок.
- [ ] `prefers-reduced-motion` учтён во всех анимациях и в шейдере.

**Скорость**
- [ ] LCP < 2,5 с, CLS < 0,1 (у картинок заданы размеры), INP < 200 мс.
- [ ] Картинки AVIF/WebP, ниже первого экрана `lazy`; шрифты `swap`, до 3 начертаний.
- [ ] Анимация только `transform`/`opacity`; шейдер на паузе вне экрана; тяжёлое подгружается лениво.

**Метаданные**
- [ ] `title`, `description`, Open Graph картинка 1200×630, `theme-color`, favicon (SVG + 180 px apple-touch).
- [ ] Ссылки внешние `rel="noopener"`, политика конфиденциальности, если собираются данные.

## Формула контраста (10 строк)

```python
def lum(h):
    h = h.lstrip('#'); r, g, b = [int(h[i:i+2], 16) / 255 for i in (0, 2, 4)]
    f = lambda c: c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * f(r) + 0.7152 * f(g) + 0.0722 * f(b)
def contrast(a, b):
    x, y = sorted([lum(a), lum(b)], reverse=True); return (x + 0.05) / (y + 0.05)
print(round(contrast('#9AA6B2', '#0B0D10'), 1))   # 7.8
```

## Проверка в браузере (инструменты Claude Code)

1. Запусти сайт (`preview_start`, либо `python3 -m http.server` в папке и `navigate` на `http://127.0.0.1:PORT`; файл через `file://` показывается статичным снимком без скриптов). Сними **пачкой** три размера: `resize_window` 375×812, 768×1024, десктоп; на каждом `computer screenshot`. **Перед снимком подожди 1,5–3 с и/или добавь `is-in` всем `[data-reveal]`**: иначе кадр поймает страницу до анимации появления и покажет пустоту. Дополнительно проверь `document.documentElement.scrollWidth > innerWidth` (горизонтальная прокрутка) и ширину самого длинного слова заголовка: широкие шрифты вроде Unbounded на 375 px переполняют контейнер первыми.
2. `read_console_messages` — ошибок быть не должно; `read_network_requests` — нет 404 и запросов к лишним доменам.
3. Клавиатура: `computer key Tab` несколько раз → `read_page`/скриншот: виден ли фокус.
4. Тёмная/светлая тема: `resize_window` с `colorScheme`.
5. Reduced motion: через DevTools-эмуляцию недоступно напрямую — проверь `matchMedia` в `javascript_tool` и убедись, что код читает его.
6. Исправь всё найденное за один заход, повтори проверку один раз и останавливайся (не полируй бесконечно).
